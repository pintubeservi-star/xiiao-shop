# VENDIA — Identidad de marca

**Nombre:** VENDIA  
**Descriptor:** Gestión inteligente para tu negocio.  
**Promesa:** Todo tu negocio, en un solo lugar.

VENDIA es una plataforma SaaS independiente para comercios, tiendas, restaurantes y pequeñas y medianas empresas. Reúne catálogo, punto de venta, inventario, pedidos, caja, reportes y facturación electrónica en una experiencia simple.

## Personalidad
Clara, confiable, práctica y moderna. Lenguaje cotidiano, sin exigir conocimientos contables o tecnológicos. Diseñada primero para móvil, pero cómoda en tablet y computadora.
